# Horizon Estates architectural parallax pack

A prompt-and-assets reference for an architectural property brand: a residence on
a mountain, layered sky and mist, and landscape transitions that form a continuous
page. This is not a ready-made website or a completed WordPress theme.

## Platform and use modes

Use the user's selected or existing project/host stack; otherwise choose a suitable
responsive frontend. WordPress is optional, including for verbatim design reuse.
The source prompt's WP/Gutenberg deliverables do not select the platform. Preserve
the original document and record technical adaptations in the working prompt.
See ../creative-direction.md.

- **Verbatim:** select the relevant source prompt/pass and approved image set;
  reproduce its composition and interactions, adapting only necessary platform
  instructions. The golden-hour direction prioritizes Orange assets.
- **Adapted:** use the layered composition, landscape continuity and motion method
  for another brand, palette, page structure or interaction. Neither orange nor
  purple is a rule for unrelated projects; scroll effects remain optional.
- **Hybrid:** name the locked composition, assets, text or behaviours, then combine
  the flexible parts with the user's other ideas and references.

## Build and review guidance

For close video reuse, apply the [video audit](horizon-estates-video-audit.md), not
just this asset inventory. Also apply the user-selected
[headline placement reference](horizon-estates-headline-reference.md): anchor the
inner phrase edges near the visible upper house with breathing room, keeping every
letter readable. Check ultrawide sizes as well as typical desktop viewports.
The finished pass uses a close foreground residence,
headline occlusion, lower-left hero copy/actions, a pill navigation, a bright warm
statement, ten-label strip, animated metrics before tall residence cards, full-width
advisory rows and a left-aligned dark closing scene. Section entrances, statement
emphasis and numerical animation are separate behaviors; avoid leaving all lower
content fully static. Do not copy the prototype's excessive cloud coverage.

For a close build, reuse the supplied images; the source does not require new
generation. When the user wants new media, Replicate remains the default provider.
Show actual new/selected assets in chat and obtain approval before public website,
preview, CDN or repository use. Private backup is separate from media approval.

Keep navigation above decorative transforms. Establish the static composition
before adding parallax; use only the layers needed, preserve the residence and
headline legibility, and blend adjacent landscapes without rectangular edges.
If using the source's suggested GSAP/ScrollTrigger/Lenis approach, coordinate
updates and cleanup; it is an implementation option, not a required stack.

Test forward/reverse scrolling, image decode, resize/orientation changes, every
landscape seam, mobile crops and horizontal overflow. Reduce mobile parallax and
avoid long pins. Reduced-motion and no-JavaScript states must retain readable
content and usable navigation. Review actual sizes and crops before optimizing
project copies; preserve the source originals.

Inspection verified PNG decoding, dimensions, alpha and document archive/XML
integrity. No site was built or runtime/mobile behaviour tested during ingestion.
No separate license was supplied with these files; retain provenance and resolve
rights for intended use rather than treating a shared link as redistribution permission.

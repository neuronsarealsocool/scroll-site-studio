# Verification

Use an active tab; hidden previews can throttle animation frames. Inspect actual
pixels as well as currentTime, dimensions, readyState and seeking. A seek event
alone does not establish that a real video frame painted.

| Check | Evidence |
|---|---|
| Every boundary, forward/reverse | Scenes advance with no empty stage |
| Loading and fast jumps | Correct poster, eventual live frame, no permanently stuck seek |
| Desktop/portrait and rotation | Paired media/posters and correct native dimensions |
| Ending and release | True last still, restored copy, ordinary content/footer reachable |
| Keyboard | Skip/navigation work; invisible copy does not trap focus |
| Reduced motion, save-data, failure | Useful still fallback, no long empty spacer |
| Business controls | Real outcomes, or explicit sample/unconnected labels |

Scroll Craft's harness adds intermediate frame/contrast/poster checks and contact
sheets. Use it only where the host allows that browser-control route; otherwise use
supported browser tools and state manual coverage. Inspect sheets, not just reports.
A green harness cannot establish aesthetics, exact room consistency or iPhone behaviour.

Test phone/desktop widths. Physical iOS/Android is separate. If a phone freezes,
compare working/failing clips on that same device and use the vendor diagnostic when
appropriate. Locate loading/decoding/painting/encoding faults before buying new media.
Do not publish diagnostics containing private inputs. Report untested conditions.
